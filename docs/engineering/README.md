# Engineering

Documentação de **engenharia** do SmartFood — histórico de decisão técnica e de produto, distinto do conteúdo funcional que vive em `product/`.

- `review-notes/` — um arquivo `missao-XXXX-review-notes.md` por missão, criado na primeira rodada de revisão (não retroativamente). Registra o quê mudou, **por quê**, e trade-offs aceitos conscientemente em cada rodada.
- `adr/` (Architecture Decision Records) — adotado em 2026-07-11, em paralelo às missões (não só "a partir de uma missão"): toda decisão estrutural relevante vira um ADR assim que é tomada, dentro ou fora de uma missão formal. Ver `adr/README.md`.
- `CHANGELOG.md` — a criar quando o primeiro código for versionado (Missão 0007/0008 em diante).
- `RELEASE_NOTES/` — a criar a partir do primeiro deploy real.
