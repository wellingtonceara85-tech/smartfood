# Platform

Esta pasta existe por consistência estrutural (`product/ · platform/ · business/ · engineering/`), mas **não contém cópia dos documentos da Smart Platform**.

A Smart Platform é compartilhada entre todos os produtos da empresa (SmartOS, SmartNCM, SmartFood, futuros) e por isso vive em um local único, fora de qualquer projeto individual:

`C:\Users\AGIL\Documents\Smart Platform\INDEX.md`

**Por quê não duplicar aqui:** copiar os documentos para dentro do SmartFood criaria duas fontes de verdade que divergiriam com o tempo — exatamente o problema que a própria Smart Platform foi criada para evitar entre os produtos. Qualquer decisão de arquitetura, design system, RBAC ou IA do SmartFood referencia o documento canônico diretamente.
